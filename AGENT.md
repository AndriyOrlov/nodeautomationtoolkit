# AGENT.MD — Інструкції та Можливості Агента NAT

Агент розробника **Node Automation Toolkit (NAT)** відповідає за розробку, розширення та підтримку модулів автоматизації документів Word, обробки військових наказів, зведення витягів та аналізу адресатів.

---

## 🛠️ Основні функції та модулі

### 1. Модуль обробки військових наказів та витягів (`builtin_nodes/recipient_mapping.py`)
- **`Розрахунок витягів з наказів` (`builtin.order.calculate_extracts`)**:
  - Приймає текст наказу, словник відповідностей ВЧ (`mapping`) та правила виправлень (`rules`).
  - Визначає структурні параграфи, причини, підписи та пронумеровані пункти.
  - Розраховує адресатів витягів з формуванням підсумкового тексту (`summary_text`), табличного звіту `DataTable` (`table`) та словника готових витягів (`extracts`).

### 2. Алгоритми адресації та нормалізації
- **Морфологічний стемер відмінків української мови (`_stem_ukrainian_word`)**:
  - Відсікає відмінкові закінчення іменників та прикметників (`полк / полку / полком`, `окремого / окремої / окремим`).
  - Нормалізує апострофи різних типів (`'`, `’`, `ʻ`).
- **Канонічна нормалізація адресатів (`_normalize_key`)**:
  - Усі варіації згадок частини чи корпусу (`24АК`, `в/ч А2424`, `військової частини А2424`, `24-й армійський корпус`) автоматично консолідуються у єдиний канонічний ключ адресата: **`24АК А2400`** або **`24АК`**.
  - Для підпорядкованих частин витяги адресуються безпосередньо Корпусу (підпорядковані бригади окремо не виводяться).
  - Для частин безпосереднього підпорядкування (ЧБП) виводиться скорочення та закритий шифр: **`15омбр А0381`**.
  - Для районних/міських ТЦК та СП автоматично витягується обласний ТЦК: **`Волинський ОТЦК та СП`**.
- **Форматування діапазонів пунктів (`_format_item_numbers_range`)**:
  - Автоматично перетворює списки пунктів у діапазони через дефіс: `1,3,4-7,9,10,11-25`.

2. Execution-ноди містять: `execution_inputs=("exec",), execution_outputs=("then",), preview_policy="never"`.
3. Імпорт `python-docx` має бути лінивим усередині функції (наприклад, `from docx import Document`).
4. Автоматична верифікація після внесення змін: `pytest`.
