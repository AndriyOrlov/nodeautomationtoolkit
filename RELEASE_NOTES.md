# Node Automation Toolkit 0.3.2

Відкриті найменування тепер можна знайти в наказі, згрупувати, зіставити з шифром і
за один прохід перетворити на декілька DOCX-витягів.

## Головне

- CSV/XLSX-таблиця: відкрите найменування, шифр і куди направляється;
- підрахунок знайдених пунктів, список відсутніх відповідностей і табличний звіт;
- причина та багатoабзацний пункт визначаються як цілі блоки;
- заголовок, основна частина та підпис відокремлюються без плейсхолдерів;
- окрема DOCX-заготовка може задавати поля, таблиці, відступи й оформлення;
- `Повне прев'ю у Word` відкриває реальний перший результат перед збереженням пакета;
- `Створити файл` і `Перейменувати файл`;
- `Розбити текст на слова` створює підписані динамічні виходи та зберігає їх у графі;
- `Показати таблицю` та `Зберегти таблицю CSV`.

## AI-помічник

OpenAI API, LM Studio й Ollama доступні в одному вікні. Для OpenAI використовується
Responses API без інструментів і без збереження відповіді на стороні API. Надсилаються
лише опис сценарію, каталог нод і топологія графа без параметрів, шляхів та документів.

Якщо ноди бракує, помічник готує чисту Python-ноду. Код завжди показується користувачу,
проходить статичну перевірку й установлюється лише після явного підтвердження. Для таких
нод заблоковані файли, мережа, shell і динамічне виконання коду.

## Інтерфейс

- у кожній ноді є кнопка з поясненням входів і виходів;
- права панель схована та відкривається кнопкою;
- стара форма 1.0 прихована, але її можна ввімкнути з панелі;
- код користувацької Python-ноди видно прямо всередині ноди.
