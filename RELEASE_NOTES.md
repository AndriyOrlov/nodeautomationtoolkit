# Node Automation Toolkit 0.4.0

Версія додає власну локальну LLM без Ollama та LM Studio.

## Локальне розуміння наказу

- Qwen3 4B Q4_K_M підтримує українську та працює через llama.cpp/Vulkan;
- кнопка `Локальна модель` встановлює рушій і модель приблизно на 2,5 ГБ;
- після встановлення інтернет не потрібен;
- сервер доступний лише локально, працює без Web UI, мережі й інструментів;
- нода `AI: розібрати структуру наказу` визначає шапку, параграфи, причини,
  шапки дій, цілі багатоабзацні пункти, підпис та блок засвідчення;
- невпевнені місця повертаються окремим списком для ручної перевірки;
- модель не переписує Word: вона повертає тільки структуру, а файли створює
  детермінований Python-код.

До релізу також додано тестову XLSX-таблицю з 10 повністю вигаданими
відповідностями.

## Оновлення

Відкрийте **Встановити патч**, виберіть
`NodeAutomationToolkit-v0.4.0.natpatch.zip`, збережіть граф і один раз
перезапустіть застосунок. Потім натисніть **Локальна модель** та встановіть її.
