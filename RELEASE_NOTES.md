# Node Automation Toolkit 0.2.0

Перший робочий Word-реліз локального Blueprint-подібного конструктора автоматизацій.

## Основне

- редактор графів на NodeGraphQt;
- окремі дроти даних і виконання;
- ноди `Start`, `Branch`, `Sequence`;
- локальні системні вікна відкриття та збереження файлів;
- JSON-сценарії `.nat.json`;
- Python-функції як користувацькі ноди;
- локальний LLM-помічник для створення нод і графів;
- базові файлові, текстові та логічні операції.
- спеціалізовані Word-типи й ноди для читання, пошуку, створення та збереження DOCX;
- фінальна нода перегляду результату;
- швидкий тестовий Word-граф із верхньої панелі;
- постійні графи в документах користувача та автоматичне відновлення роботи;
- користувацькі Python-ноди зберігаються в AppData й переживають оновлення програми.

Це рання версія для перевірки Word-пайплайна. Повний аналіз структури наказу,
групування за відправниками та формування витягів будуть наступним шаром.

## Запуск

Завантажте Windows ZIP, розпакуйте його та запустіть `NodeAutomationToolkit.exe`.
Мережеве підключення для роботи програми не потрібне.
