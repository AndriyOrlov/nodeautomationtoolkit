# Node Automation Toolkit 0.3.0

Live-відладка Blueprint-графа й основа для малих офлайн-оновлень.

## Основне

- ноди видаляються кнопкою, `Delete` і через контекстне меню;
- кожна нода має кнопку виконання, кольоровий стан і блок прев'ю;
- окрему ноду можна виконати разом лише з потрібними залежностями;
- безпечні ноди перераховуються у фоні після зміни параметрів і дротів;
- `Відкрити файл` має системну кнопку вибору файла прямо всередині ноди;
- DOCX одразу показує назву, розмір та уривок тексту;
- повний запуск графа також оновлює стани нод у реальному часі;
- графи надалі оновлюються без перезапуску програми;
- додано локальний інсталятор `*.natpatch.zip` для майбутніх малих оновлень;
- Windows CI перевіряє створення, вбудовані елементи та видалення нод.

Версію 0.3.0 потрібно один раз завантажити повним Windows ZIP. Наступні зміни,
які не додають нових системних залежностей, можна буде ставити малим офлайн-патчем.

## Запуск

Завантажте Windows ZIP, розпакуйте його та запустіть `NodeAutomationToolkit.exe`.
Мережеве підключення для роботи програми не потрібне.
