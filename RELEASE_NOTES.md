# Node Automation Toolkit 0.3.3

Цей малий патч додає точні операції зі сторінками Word у пакетних сценаріях.

## Нові ноди

- `Видалити сторінку`: приймає номер, `перша` або `остання`;
- `Вставити сторінку`: додає сторінку на початок, у кінець або перед указаним
  номером;
- якщо шлях до DOCX-заготовки порожній, вставляється чиста сторінка;
- якщо шлях указаний, вставляється готовий DOCX зі збереженням Word-оформлення.

Операції виконуються для кожного документа пакета. Для точного визначення меж
сторінок потрібні Windows і встановлений Microsoft Word.

## Оновлення

У програмі відкрийте **Встановити патч**, виберіть
`NodeAutomationToolkit-v0.3.3.natpatch.zip`, збережіть граф і один раз
перезапустіть застосунок.
