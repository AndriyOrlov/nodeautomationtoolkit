# Наскрізна перевірка генерації витягів

Проганяє **справжній** `App.run_extracts` на вигаданому наказі, який відтворює
структуру офіційних зразків (див. AGENT.md розд. 12). Реальні накази лежать на
`E:`, куди агенту заборонено, тому весь прогін — на `C:`.

```bash
python scripts/e2e_extracts/make_fixtures.py <тека>
python scripts/e2e_extracts/run_extracts_e2e.py <тека> .
```

Що перевіряє тестовий наказ:

| Правило | Як перевіряється |
| --- | --- |
| 4.2 — ТЦК у біографічному рядку не є адресатом | пункт 3 згадує районний ТЦК у рядку «Підлягає направленню…» |
| 4.2.2 — частина під корпусом дає ОДИН витяг на корпус | пункт 1: обидві частини підпорядковані 90 АК |
| 4.2.3 — «Кому»/«Куди» беруться з корпусу | у витягу має бути адресат і дислокація корпусу |
| внутрішнє переміщення | пункт 2: «цього самого загону» |
| зворот останнього аркуша | ДВА блоки розсилки, перший — таблицею |
| геометрія 1-в-1 | шаблон навмисно має «ворожий» стиль Normal (justify + 1.25 см) |

Очікуваний результат: 3 витяги — `90 АК А0090`, `3 отз А0003`, `4 отп А0004`;
у документі 0 таблиць і жодного рядка службового хвоста.

Прогін наприкінці відкриває результат у Word і сам закриває **лише той**
екземпляр, який відкрив.

## Варіант зразка: підписант і засвідчувач ТАБЛИЦЕЮ

Бойовий зразок верстає блок «підписант / Згідно з оригіналом / засвідчувач»
таблицею 5×2, а `{{виконавець}}` ставить одразу за нею — останнім абзацом
документа. Цю верстку перевіряє окремий шаблон:

```bash
python scripts/e2e_extracts/make_fixtures.py <тека>
python scripts/e2e_extracts/make_template_table_signer.py <тека>
python scripts/e2e_extracts/run_extracts_e2e.py <тека> .
```

Що має вийти: ті самі 3 витяги, але з таблицею на ПʼЯТЬ рядків — підписант
наказу (посада, звання з ПІБ), «Згідно з оригіналом», засвідчувач (посада,
звання з ПІБ), — а виконавець опущений донизу сторінки порожніми абзацами
**після** таблиці. Підписант береться з наказу; якщо його не розпізнано,
рядки з тегами `{{підписант_…}}` мають зникнути разом із рядками таблиці.

Саме на цьому шаблоні ловляться дві помилки, яких немає на шаблоні з абзаців:
зависання назавжди на першому витягу (порожню комірку таблиці Word не видаляє
й помилки не кидає, тож цикл зняття відступів перед виконавцем був вічним) і
зникнення рядка «Згідно з оригіналом» разом із рядками підписанта.

## Пункт «ВИКЛАСТИ В ТАКІЙ РЕДАКЦІЇ» — жодного рядка двічі

```bash
python scripts/e2e_extracts/make_fixtures_redaction.py <тека>
python scripts/e2e_extracts/check_no_duplicate_lines.py <тека> .
```

Наказ, у якому пункт цитує цілий § з преамбулою та власним пунктом. Для такого
пункту маршрутизація віддає «шапку», що заходить у рядки вступного абзацу, і
без захисту витяг друкував пункт двічі. Перевірка проганяє справжній
`run_extracts` (маршрутизацію навмисно підмінено, щоб задати саме таке
перекриття) і завершується кодом 1, якщо якийсь абзац перенесено двічі.
