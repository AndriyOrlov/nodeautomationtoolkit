# Наскрізна перевірка генерації витягів

Проганяє **справжній** `App.run_extracts` на вигаданому наказі, який відтворює
структуру офіційних зразків (див. AGENT.md розд. 12). Реальні накази лежать на
`E:`, куди агенту заборонено, тому весь прогін — на `C:`.

```bash
python scripts/e2e_extracts/make_fixtures.py <тека>
python scripts/e2e_extracts/run_extracts_e2e.py <тека> .
```

Що перевіряє тестовий наказ:

| Правило | Як перевіряється |
| --- | --- |
| 4.2 — ТЦК у біографічному рядку не є адресатом | пункт 3 згадує районний ТЦК у рядку «Підлягає направленню…» |
| 4.2.2 — частина під корпусом дає ОДИН витяг на корпус | пункт 1: обидві частини підпорядковані 90 АК |
| 4.2.3 — «Кому»/«Куди» беруться з корпусу | у витягу має бути адресат і дислокація корпусу |
| внутрішнє переміщення | пункт 2: «цього самого загону» |
| зворот останнього аркуша | ДВА блоки розсилки, перший — таблицею |
| геометрія 1-в-1 | шаблон навмисно має «ворожий» стиль Normal (justify + 1.25 см) |

Очікуваний результат: 3 витяги — `90 АК А0090`, `3 отз А0003`, `4 отп А0004`;
у документі 0 таблиць і жодного рядка службового хвоста.

Прогін наприкінці відкриває результат у Word і сам закриває **лише той**
екземпляр, який відкрив.
