# Цифровий підпис EXE повідомлень

`build_messages_qt.bat` після збірки підписує `dist\PovidomlenniaKadrovi.exe`
підписом Authenticode (SHA-256) — скриптом `sign_exe.ps1`. Підпис гарантує, що
файл не змінено після збірки, і показує видавця у «Властивості → Цифрові підписи».

## Чий сертифікат

| варіант | що дає |
| --- | --- |
| **Сертифікат підпису коду від центру сертифікації** (комерційний або відомчий PKI) | Windows довіряє одразу на всіх ПК; SmartScreen поступово перестає попереджати |
| **Власний самопідписаний** (`new_signing_cert.ps1`) | безкоштовно; підпис цілий і перевірний, але довіряють йому лише ПК, де встановлено `.cer` |

Без сертифіката EXE збирається, але лишається непідписаним — збірка про це скаже.

## Власний сертифікат — один раз на ПК, де збираєте

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\signing\new_signing_cert.ps1
```

- сертифікат із приватним ключем лягає в «Особисті» поточного користувача — звідти
  його бере збірка;
- відкрита частина — `signing\NAT_code_signing.cer` у корені проєкту (у git не йде);
- `-ExportPfx` — додатково резервна копія ключа `.pfx` під паролем. Її **не передавати**.

## Робочі ПК — щоб Windows довіряла підпису

Скопіюйте поруч `NAT_code_signing.cer` і `install_signing_cert.ps1`, запустіть:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File install_signing_cert.ps1
```

`-AllUsers` — для всіх користувачів ПК (з правами адміністратора). Адміністратор
мережі може розіслати той самий `.cer` груповою політикою в «Довірені кореневі
центри сертифікації» і «Довірені видавці».

## Готовий сертифікат (.pfx або зі сховища)

```bat
set NAT_SIGN_PFX=C:\шлях\сертифікат.pfx
set NAT_SIGN_PFX_PASSWORD=...
build_messages_qt.bat
```

або `set NAT_SIGN_THUMBPRINT=<відбиток>` для сертифіката зі сховища «Особисті».

## Мітка часу

Якщо є інтернет, до підпису додається мітка часу (`timestamp.digicert.com`):
підпис лишається чинним і після закінчення строку сертифіката. Без мережі EXE
підписується без мітки — скрипт попередить.

## Перевірити підпис

```bat
powershell -Command "Get-AuthenticodeSignature dist\PovidomlenniaKadrovi.exe | Format-List"
```
