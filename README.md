# Node Automation Toolkit

Локальний візуальний конструктор автоматизацій на Python. Ноди перетягуються на
полотно, з'єднуються портами, а сценарій зберігається у звичайному JSON.

> Версія `0.3.0`: live-Blueprint із виконанням окремих нод, прев'ю прямо в нодах,
> надійним видаленням і підтримкою малих офлайн-патчів.

> Патч `0.3.2`: таблиця відповідностей, групування за шифрами, звіт, динамічні
> порти та AI-побудова сценаріїв без передачі документів.

> Патч `0.3.3`: ноди видалення та вставлення першої, останньої або нумерованої
> сторінки; можна вставити чисту сторінку чи готову DOCX-заготовку.

> Патч `0.3.4`: шапки дій на кшталт `ЗВІЛЬНИТИ І ПРИЗНАЧИТИ до АЛЬФА`
> передають свого відправника всім наступним пунктам до нової шапки.

## Завантажити для Windows

1. Відкрийте сторінку **Releases** праворуч на GitHub.
2. Завантажте `NodeAutomationToolkit-v0.3.0-windows-x64.zip`.
3. Розпакуйте архів у звичайну папку.
4. Запустіть `NodeAutomationToolkit.exe`.

Інсталяція Python для готової Windows-збірки не потрібна. Windows SmartScreen може
показати попередження, оскільки перша збірка ще не має платного цифрового підпису.

## Уже працює

- візуальне полотно на PySide6;
- drag-and-drop нод із палітри;
- drag-and-drop локальних файлів на полотно;
- з'єднання типізованих входів і виходів;
- необов'язкова згортана панель властивостей; стара форма 1.0 прихована;
- збереження та відкриття сценаріїв `.nat.json`;
- реальне виконання ациклічного графа;
- автоматичне створення ноди зі звичайної Python-функції;
- безпечне завантаження локальних плагінів: помилка одного плагіна не ламає програму;
- базові ноди для файлів, тексту, списків і логіки;
- Blueprint 2.0 на NodeGraphQt з окремими data- та execution-портами;
- `Start`, `Branch` і `Sequence` для керування потоком;
- нативні системні вікна Windows: відкрити файл, вибрати файли або папку, зберегти як;
- LLM-помічник працює через OpenAI API, LM Studio або Ollama й створює плани графів;
- якщо потрібної ноди немає, помічник показує Python-код, перевіряє його та
  встановлює лише після підтвердження;
- API отримує тільки опис, каталог нод і топологію графа без значень, шляхів і файлів;
- AI-планувальник змінює лише граф після підтвердження й ніколи сам його не запускає.
- спеціалізовані Word-типи й ноди: читання DOCX, текст, абзаци, пошук і збереження;
- фінальна нода `Показати результат` з окремим вікном і копіюванням;
- автозбереження робочого графа та постійна папка графів у документах користувача;
- постійна папка користувацьких нод у AppData, яка не стирається після оновлення.
- видалення вибраних нод кнопкою, клавішею `Delete` або через контекстне меню;
- кнопка виконання й кольоровий стан прямо в кожній ноді;
- live-перерахунок безпечних нод після зміни параметрів або з'єднань;
- кнопка системного вибору файла всередині ноди `Відкрити файл`;
- прев'ю вибраного DOCX та результатів безпосередньо на полотні;
- виконання вибраної ноди разом лише з потрібними їй залежностями (`F6`);
- встановлення малих локальних патчів без завантаження повної portable-збірки.

## Офлайн-патчі

Версію `0.3.0` треба один раз завантажити повністю, бо старі збірки ще не мають
завантажувача патчів. Для наступних оновлень відкрийте **Встановити патч**, виберіть
файл `*.natpatch.zip`, збережіть граф і один раз перезапустіть програму. Патчі
містять лише Python-код і зазвичай важать у тисячі разів менше повного ZIP.

## Швидка перевірка Word

1. Натисніть **Word тест** на верхній панелі.
2. У ноді **Відкрити файл** натисніть **Вибрати файл…**.
3. Виберіть локальний `.docx`: назва й уривок тексту з'являться в нодах автоматично.
4. Для повного сценарію натисніть **Запустити** або `F5`.
5. Фінальна нода покаже прочитаний текст в окремому вікні.

## Пакет витягів з одного наказу

Базовий граф будується так:

1. `Відкрити файл` → `Прочитати DOCX`.
2. `Розбити наказ на блоки` визначає параграфи, причини та нумеровані пункти.
3. `Прочитати таблицю відповідностей` подає список відкритих найменувань.
4. `Згрупувати пункти за мітками` створює групи та підраховує пункти.
5. `Перетворити групи на шифри` додає адресу, готує документи й табличний звіт.
6. `Створити пакет документів` бере наказ або окрему DOCX-заготовку оформлення.
7. Пакетні ноди автоматично знаходять основну частину, додають новий підпис, приклад останньої
   сторінки й форматування сторінок.
8. `Не розривати пункти` тримає всі абзаци одного пункту разом.
9. `Видалити сторінку` та `Вставити сторінку` працюють із номером, першою або
   останньою сторінкою; вставлення підтримує чисту сторінку й DOCX-заготовку.
10. `Повне прев'ю у Word` показує перший результат із реальним макетом.
11. `Зберегти пакет DOCX` за один прохід створює всі файли в указаній папці.

Якщо один пункт містить дві мітки, він автоматично входить до двох документів.
Для точних меж сторінок, підписів і міжрядкових інтервалів потрібен установлений
Microsoft Word. Звичайний пошук і короткі текстові заміни працюють без нього.

Графи вручну зберігаються як `.nat.json` у папці
`Документи/Node Automation Toolkit/Graphs`. Поточна робота також автоматично
відновлюється після оновлення або перезапуску програми.

## Запуск для розробки

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev,windows]"
python -m nodeautomationtoolkit
```

Основна обробка Word повністю локальна. Мережа використовується лише коли користувач
явно обирає OpenAI API; документи й результати сценарію до API не надсилаються.

## Власна нода

Створіть файл у папці `plugins/nodes`, наприклад `my_nodes.py`:

```python
from nodeautomationtoolkit import node


@node(name="Додати префікс", category="Мої ноди")
def add_prefix(text: str, prefix: str = "ВИТЯГ: ") -> str:
    return prefix + text
```

Натисніть **Оновити плагіни**. Аргументи функції стануть входами й параметрами,
а тип результату стане виходом ноди.

Плагіни є Python-кодом і мають повний доступ до комп'ютера. Підключайте лише
власні або перевірені файли.

## Структура

- `src/nodeautomationtoolkit/core` — моделі, реєстр нод, виконання та JSON;
- `src/nodeautomationtoolkit/ui` — редактор графа й головне вікно;
- `src/nodeautomationtoolkit/builtin_nodes` — стандартні Python-ноди;
- `plugins/nodes` — локальні користувацькі плагіни;
- `tests` — тести ядра.

## Наступний етап

1. Інтерактивне підтвердження неоднозначно знайдених місць у макеті.
2. OpenCV/OCR-гілка для відсканованих документів.
3. Готовий сценарій створення витягів.
4. Цифровий підпис Windows-збірки.
