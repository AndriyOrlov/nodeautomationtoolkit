# Node Automation Toolkit (NAT) — Агентська інструкція та Документація проекту

## 🌟 Огляд проекту
**Node Automation Toolkit (NAT)** — це графічна та консольна платформа автоматизації діловодства, опрацювання наказів, пакетної роботи з документами Word (`.docx`), Excel (`.xlsx`), файловою системою та ОС Windows за допомогою візуальних нодових графів та штучного інтелекту (LLM).

---

## 🛠️ Реалізований функціонал та Модулі

### 1. Інтеграція штучного інтелекту (Google Gemini 3.0, OpenAI, Local LLM)
- **Підтримка провайдерів**:
  - `Google Gemini API` (маршрутизування OpenAI-сумісного `/chat/completions`).
  - `OpenAI API` (`gpt-5.6`, `gpt-5.0`, `gpt-4o`, `o3-mini`).
  - `LM Studio` / `Ollama` / `Embedded Local Qwen`.
- **Автоматичне оновлення моделей через `/v1/models`**:
  - Кнопка **`🔄 Оновити`** виконує живий запит до сервера провайдера та заповнює випадаючий список актуальними моделями.
- **Локальне збереження налаштувань (`QSettings`)**:
  - Усі введені API-ключі, вибрані моделі та адреси API зберігаються локально в Windows Registry (`HKCU\Software\DEADSUE.ART\NodeAutomationToolkit`) і відновлюються автоматично.
- **Жорсткий промпт та аналіз наявного графа**:
  - AI-помічник аналізує існуючі ноди на полотні, створює нові з'єднання та генерує специфікації відсутніх Python-нод у `missing_nodes` із кнопкою швидкого створення.

### 2. Спеціалізоване військово-адміністративне діловодство та Накази
- **Картування та пошук військових частин (`builtin.order.map_military_units`)**:
  - Пошук відкритих найменувань частин у тексті наказу.
  - Заміна відкритих найменувань на закриті шифри (`в/ч АXXXX`) за Excel/CSV таблицею відповідностей.
  - Збереження юридичної преамбули наказу (*«Відповідно до пунктів... ЗВІЛЬНИТИ з займаних посад і ПРИЗНАЧИТИ:»*).
  - Підтримка параграфів (**`§ 1`**, **`§ 2`**) та об'єднання багаторядкових пунктів із датами народження (`1997 р.н.`), ІПН та `Підставою:` в єдиний блок.
- **Пакетне створення витягів за ВЧ (`builtin.order_batch.create_unit_extracts`)**:
  - Автоматична генерація окремих документів Word (`Витяг_А1234_№100.docx`) для кожної частини з шапкою наказу, параграфом § та пунктами особового складу.
- **Організація наказів за номерами та папками (`builtin.word_batch.organize_by_number`)**:
  - Автоматичне зчитування дати та номера наказу з DOCX.
  - Створення папок `Наказ № [Номер]` та перейменування у формат `прим_2_[Дата]_[Номер].docx`.

### 3. Пакетне розширене перейменування та Робота з файлами
- **Повноцінний ренеймер файлів (`builtin.files.advanced_rename`)**:
  - Додавання префіксів, суфіксів, обрізання N символів спочатку/з кінця, обрізання до/після вказаного символу, пошук та заміна за регулярними виразами.
- **Ноди роботи з папками**:
  - Створення папок (`builtin.files.create_folder`), перейменування папок (`builtin.files.rename_folder`), переміщення файлів (`builtin.files.move_file`).

### 4. Робота з таблицями Excel (`.xlsx`)
- **Прочитати аркуш Excel (`builtin.excel.read_sheet`)**: зчитування у `DataTable` з автовизначенням колонок та заголовків.
- **Записати у комірку Excel (`builtin.excel.write_cell`)**: точкове оновлення конкретної комірки (`B5`, `C10`).
- **Зберегти таблицю в Excel (`builtin.excel.save_table`)**: вивантаження `DataTable` у новий `.xlsx` файл.
- **Заміна тексту в Excel (`builtin.excel.replace_text`)**: масовий пошук та заміна тексту у комірках.

### 5. Керування ОС Windows та Система Сповіщень
- **Запустити команду Windows (`builtin.windows.run_command`)**: виконання PowerShell / CMD команд.
- **Відкрити файл чи програму (`builtin.windows.open_path`)**: відкриття файлів/URL у стандартних програмах.
- **Буфер обміну Windows (`builtin.windows.clipboard`)**: копіювання та читання з системного буфера обміну.
- **Сповіщення Windows (`builtin.windows.send_notification`)**: сповіщення у Центрі повідомлень.

### 6. Автономне пакування та Консольний CLI-запуск
- **Упакувати у standalone-пакет (`builtin.project.export_standalone`)**: створення самостійних запускних наборів (.bat + .json).
- **Консольний CLI-режим**: запуск будь-якого сценарію без відкриття вікна GUI редактора за допомогою `NodeAutomationToolkit.exe --run scenario.nat.json`.

### 7. Графічний редактор та Візуальне групування
- **Візуальне групування рамкою (`Backdrop`)**: об'єднання виділених нод у кольорові блоки із власними заголовками (**`Ctrl+G`** або кнопка *🔲 Згрупувати рамкою*).
- **Старт гілки (`builtin.flow.sub_start`)**: незалежні початкові точки для виконання окремих підсценаріїв (`F6`).
