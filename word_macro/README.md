# Перевірка наказу прямо у Word (макроси)

Два макроси. Обидва позначають знахідки прямо у відкритому документі:
**червоне** виділення — помилка, **жовте** — варто глянути, на кожному — примітка Word.
Документ **не зберігається**: збережіть його або закрийте без збереження.
Повторний запуск спершу прибирає старі позначки макросу.

| Макрос | Для кого | Що потрібно |
|---|---|---|
| `NAT_CheckOrderOffline` | студент, будь-який ПК | лише Word + `nat_rules.txt` |
| `NAT_CheckOrderWithProgram` | ви, ПК з програмою | програма генератора |

**Обидва макроси перевіряють:**

| Що | Колір |
|---|---|
| Нумерація: пропуск, повтор, підпункт не на місці (наскрізна через увесь наказ) | червоне |
| «1.Капітана» — без пропуску після номера | жовте |
| РНОКПП: контрольна цифра | червоне |
| РНОКПП: дата/рік народження чи «Народився/Народилася» не збігаються | жовте |
| Номенклатура: звільнення з військової служби вище підполковника | червоне |
| Алфавітний порядок прізвищ у кожному § і під кожною підшапкою | жовте |
| Рік народження: лише «1978 р.н.,» (або «1979 р.н.» + табуляції + РНОКПП + крапка) | жовте |
| «у ЗС – із 07.1991.» / «у ЗС – із 06.1997 по 06.2010 та з 01.2017.» | жовте |
| Задвоєні знаки «..», «,,», «;;», «!!» і два пробіли підряд | жовте |
| Перед підписантом наказу — рівно 2 порожні абзаци | жовте |
| Коротке слово (з, на, і, у, до, по, від…) або число в **кінці** рядка; на початку — можна; «про», «та», «як» — можна; біоблок (відступ зліва від 4 см) не перевіряється | жовте |

`NAT_CheckOrderWithProgram` додатково бере з програми: адресатів і частини з таблиці,
історію осіб з індексу попередніх наказів. Корабельні звання макроси не перевіряють
(лише Сухопутні війська).

## Файли

- `NATCheckCore.bas` — модуль перевірки (потрібен для обох макросів);
- `NATProgramCheck.bas` — кнопка «перевірити програмою» (лише там, де є програма);
- `nat_rules.txt` — правила й тексти (UTF-8). Його збирає програма з довідників:
  `python scripts/word_macro/build_rules.py`. Межа номенклатури — у
  `personnel/dictionaries/nomenclature.csv`; після зміни — перезібрати `nat_rules.txt`
  і дати студенту новий файл.
- `Приклад наказу для перевірки.docx` — вигаданий наказ із навмисними помилками.

## Встановлення (один раз)

1. Word → **Alt+F11** (редактор VBA).
2. Ліворуч виберіть **Normal** → меню **File → Import File…** → `NATCheckCore.bas`.
   На ПК з програмою так само імпортуйте й `NATProgramCheck.bas`.
3. Закрийте редактор. Word збереже макроси в `Normal.dotm` — вони працюватимуть у
   будь-якому документі.
4. Кнопка: **Файл → Параметри → Панель швидкого доступу** → «Вибрати команди з:
   **Макроси**» → `Normal.NATCheckCore.NAT_CheckOrderOffline` (і/або
   `Normal.NATProgramCheck.NAT_CheckOrderWithProgram`) → **Додати** → **Змінити**
   (назва й значок).

Перший запуск:

- `NAT_CheckOrderOffline` попросить вказати `nat_rules.txt` (запам'ятовує шлях). Можна
  покласти файл поруч із `Normal.dotm` (`%APPDATA%\Microsoft\Templates`) — тоді не питає.
- `NAT_CheckOrderWithProgram` попросить теку програми: ту, де лежить
  `GeneratorVytyagivQt.exe` (зібрана програма — тека `dist\GeneratorVytyagivQt`) або
  `generate_extracts_qt.py`. Змінити теку — макрос `NAT_ChooseProgramFolder`.
  Таблиця й індекс беруться з налаштувань програми.

## Перевірка, що все працює

Відкрийте `Приклад наказу для перевірки.docx` і запустіть `NAT_CheckOrderOffline`.
Має бути 3 помилки й 1 зауваження:

- пункт 3 — «після пункту 1 йде пункт 3» (червоне);
- пункт 3 — РНОКПП не проходить контрольну перевірку (червоне);
- пункт 3 — «звання особи «Полковника» вище за підполковник» (червоне);
- пункт 1 — дата народження 02.03.1988 не збігається з РНОКПП (жовте).

«ШТАБУУ» в пункті 1 не позначається: перевірку незнайомих слів у посадах вимкнено
(на реальних наказах давала забагато жовтого). Увімкнути — рядок `check.spelling=1`
у `nat_rules.txt` (або `CHECK_POSITION_SPELLING = True` в `order_review/check.py` і
перезібрати правила).

## Чим макрос без програми слабший

- не знає таблиці відповідностей та індексу: адресатів та історії осіб за попередніми
  наказами не перевіряє;
- підписний хвіст наказу не відсікає.

Нумерація, РНОКПП і номенклатура дають **точно ті самі** знахідки, що й програма —
це перевіряє `tests/test_word_macro.py`, проганяючи ядро макросу через `cscript`.
